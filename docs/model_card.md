# 1. Model Overview

The **STP (Travel Intent Classification Model)** performs binary classification at the **session level** to identify user travel intent, distinguishing between:

- **Leisure Travel Intent**
- **Necessary-purpose Intent**

The model is built using **LightGBM (Light Gradient Boosting Machine)**, an efficient implementation of Gradient Boosting Decision Trees (GBDT).

### Core Principle

- **Sequential Decision Tree Training**:
  LightGBM sequentially builds multiple decision trees. Each new tree focuses on fitting the residual errors from previous predictions, gradually reducing prediction errors through iterative optimization.

- **Prediction Output**:
  The final travel intent classification result is generated by combining the weighted outputs of all decision trees.

- **Algorithm Advantages**:
  Compared with traditional GBDT, LightGBM provides significant improvements in training speed and memory efficiency, enabling efficient processing of high-dimensional features.

# 2. Feature Engineering

## Feature Framework

All model input features are generated through aggregation of user behaviors across all associated sessions within the tracking window.

The feature system covers multiple dimensions, including:

- Time
- Location
- Product
- User profile
- Decision-making behavior
- Cross-business/platform signals

| Category | Sub-category | Example Features |
|---|---|---|
| **Time** | Check-in Date Type | `checkin_datekey_cnt`, `holiday_weekend_vacation_checkin_datekey_cnt`, etc. |
| | Booking Behavior | `lead_time` (advance booking days), etc. |
| **Location** | City Type | City tiers: `tier1_city_cnt`, `tier2_city_cnt`, etc.; Tourism characteristics: `tourism_core_city_cnt`, `tourism_big_city_cnt`, etc. |
| | AOI Type | AOI landmarks: `scenic_area_cnt`, `transport_hub_cnt`, `university_cnt`, `hospital_cnt`, etc. |
| | Travel Distance | `travel_distance`, etc. |
| **Product** | POI Type | Hotel ratings: `star3_cnt`, `star4_cnt`, `star5_cnt`, etc.; Hotel types: `business_cnt`, `couple_cnt`, etc. |
| | Goods Type | `king_room_cnt`, `double_room_cnt`, etc. |
| **User** | Demographics | `is_young`, `is_middle_age`, etc. |
| | User Value | `is_high_value`, etc. |
| | User Segment | `is_business_elite`, `is_college_student`, etc. |
| **Decision Behavior** | Browsing Behavior | Browsing duration: `stay_time`, `poi_list_time`; Browsing frequency: `poi_list_cnt`, `poi_info_cnt`, etc. |
| | Search Behavior | `search_cnt`, etc. |
| **Cross-business / Platform** | Ticketing & Vacation | `travel_session_cnt`, etc. |
| | External Traffic Source | `rednote_cnt`, `waitou_cnt`, etc. |

# 3. Model Performance

## Test Set Evaluation

| Class | Precision | Recall | F1-score |
|---|---:|---:|---:|
| Necessary-purpose Intent | 0.81 | 0.84 | **0.82** |
| Leisure Travel Intent | 0.87 | 0.84 | **0.86** |
| **Accuracy** | **0.84** | | |
| **Macro Avg** | 0.84 | 0.84 | 0.84 |
| **Weighted Avg** | 0.84 | 0.84 | 0.84 |

> The model demonstrates strong classification capability for both leisure travel and necessary-purpose intents, achieving an overall accuracy of **0.84**, with F1-scores of **0.82** and **0.86** for the two categories.

A higher Gain value indicates that the feature is used more frequently and contributes more significantly to model decisions.

> **Note:**  
> Feature importance only measures the contribution of each feature to model decisions. It does not indicate the direction of influence — for example, whether a larger feature value increases the probability of predicting leisure travel or necessary-purpose intent.

# 5. Data Warehouse Deployment

The **Travel Intent Classification Model** has achieved **end-to-end coverage from user visits (UV) to payment conversion**.

Intent labels are directly deployed into core traffic and order data warehouse tables:

| Data Table | Description |
|---|---|
| `app_hotel.dws_log_pv_stp_di` | Traffic intent table |
| `app_hotel.dws_log_order_trade_stp_di` | Order intent table |

> **Note:**  
> Due to the cross-session tracking mechanism, historical records within the previous 30 days may be updated. The expected change rate is approximately **4%**.
